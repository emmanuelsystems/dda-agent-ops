# Skills

This folder stores modular DDA skill specs.

## Current Status

Extracted skills in this folder are draft/review-only unless a reviewer explicitly promotes them.

## Draft Skills

- `dda-codex-intent-router/` - stabilizes messy DDA or Systems Shaper intent into review-only routing, run, completion, and memory-candidate packets without making external-write, automation, runtime, or canon claims.
- `dda-evidence-decision-review/` - converts DDA/ATDL transcripts, generated notes, connected context, and repo evidence into review-only decision packets with proof boundaries.
- `todo/` - converts raw notes, Slack updates, meeting notes, or brainstorms into `artifacts/todo.md`.
